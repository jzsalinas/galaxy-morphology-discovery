# OC3 Cross-Observer Grouping Autonomy Policy Core Contract 001

## Purpose

The universal policy decides only whether an epistemically material action remains inside the frozen cross-observer grouping mandate. Action-specific validators own scientific and transport correctness.

## Generic policy

The Policy Core contains no stage ID, candidate filename, command, resource URL, or scientific-action identity. The waiting state alone binds the first candidate by exact project-relative path and full-file SHA-256. Standing authorization independently binds that waiting state and candidate. Before the first completion, registration accepts only that state binding; later registrations are generic.

The generic action contract requires a nonempty subset of mandate authority classes; exact specification, validator receipt, implementation, command, manifest, branch, permit-path, reservation, retry, resume, and firewall bindings; and no prohibited requested scope. Network actions require a literal sealed manifest. Reservations cannot exceed mission budgets.

Every permit is immutable and bound to candidate, state, authorization, command, budgets, authority classes, and firewall. Consumption is canonical, single-use, and keyed by permit SHA. Completion requires the consumption marker, exact terminal SHA and counters, and bounded deltas. STOP and the four scientific terminals are closed and ledgered.

## Immutability and Git firewall

The manifest binds this contract and both governor implementation files. Mutation while active requires `STOP_REQUIRES_HUMAN`. Runtime evidence trees, scientific table bodies, archives, credentials, and noncompact artifacts cannot be staged by the governor auditor.
