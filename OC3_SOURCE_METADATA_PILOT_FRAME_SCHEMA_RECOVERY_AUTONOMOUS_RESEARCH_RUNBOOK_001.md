# Pilot-Frame Schema Recovery Autonomous Research Runbook 001

1. Verify the exact terminal base, closed predecessor artifacts, provider
   contracts, Policy Core, mandate, waiting state, first candidate and receipt.
2. Obtain separate standing human authorization bound to the exact waiting
   state and candidate; bootstrap creates none.
3. Activate, register, evaluate and issue one new schema-recovery permit.
   Consume it before launching the worker.
4. Validate full physical contracts before cell access. Decode uppercase root
   and lowercase regional identity fields exactly, normalize only into the
   canonical identity layer, and never try alternate spellings.
5. Create output/intent, launch exactly one worker, capture bounded diagnostic
   evidence, validate the unchanged frame and write a terminal.
6. Transition with zero request/body/retry deltas. A valid frame closes
   `SCHEMA_RECOVERED`; physical/input/invariant violation closes
   `SCHEMA_INTEGRITY_FAILED`; environment/runtime inability closes
   `SCHEMA_RECOVERY_INCONCLUSIVE` or governed STOP.
7. Finalize through the governor. Never continue to Data Lab, source counts or
   rows, topology, matching, radius, threshold, Panel V3 or P1.

A consumed permit is never replayed. Preserve partial evidence and require
human review after an uncontracted interruption.
