# OC3 Observational Multiplicity Autonomy Policy Core Contract 002

## Purpose

This universal policy decides only whether an epistemically material action remains inside the frozen observational-multiplicity mandate. Strict action-specific validators remain responsible for scientific and technical correctness.

## State-driven first action

Universal code contains no candidate identity. The waiting state is the sole first-action authority and binds its candidate with an exact project-relative path and full-file SHA-256. Validation requires that the path remain inside the project, the file exist and match its SHA, the JSON be canonical and sealed, and the candidate pass the generic action contract.

Standing authorization independently binds the waiting-state path/SHA and the state-declared first-candidate path/SHA. Activation revalidates both. Before `last_completed_stage` exists, registration accepts only the exact state binding. Subsequent registrations are generic.

## Preserved generic contract

`OC3_OBSERVATIONAL_MULTIPLICITY_ACTION_CONTRACT_002` continues to support nonempty mandate authority subsets; bounded request, body, retry, and concurrency reservations; literal manifests for network actions; prospectively frozen exact-resource retries; closed scientific firewalls; empty requested prohibited scopes; exact Git assertions; action receipts; implementation/specification bindings; and immutable candidate-declared permits.

Permit consumption is identified only by permit SHA under `oc3/OBSERVATIONAL_MULTIPLICITY_AUTONOMY_LEDGER/PERMIT_CONSUMPTION/`. Completion revalidates policy, authorization, state, candidate, permit, canonical marker, terminal SHA/counters, reservations, and mission budgets. STOP and scientific terminals remain closed and ledgered.

## Immutability

Manifest 002 binds this contract and both V2 governor implementation files. After standing authorization, any member mismatch fails closed as `POLICY_CORE_MISMATCH`; changing V2 requires `STOP_REQUIRES_HUMAN`. V1 remains immutable historical evidence.
