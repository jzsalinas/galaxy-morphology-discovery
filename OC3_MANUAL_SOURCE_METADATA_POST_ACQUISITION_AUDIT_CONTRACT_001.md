The later Codex task must remain offline and must not trust process success alone. It must validate the binding and manifest seals, recompute all RAW sizes and SHA-256 hashes, verify the five literal query identities and the provider/transport contract, prove each response complete, and retain Content-Type as observed provenance.

It must then run the frozen schema parser, count parsers and row validators; enforce row caps, count/row equality, ordering, identity, target-brick and holdout firewalls; and issue a separate accept/reject decision for each dataset. Only a fully accepted audit may support a prospective zero-network Run-005 evidence-ingestion candidate. The manual manifest itself is never scientific acceptance.

If any response is missing, partial, hash-inconsistent or semantically invalid, preserve the evidence and stop. Do not perform network repair, raise the timeout, add retries, split queries, switch to async access or alter scientific criteria during the audit.
