# Pilot-Frame Recovery Policy Core Contract 001

The manifest freezes this mission's governor and CLI by SHA-256. While active, mutation or mismatch requires `STOP_REQUIRES_HUMAN`. The governor validates exact authorities, mandate, branch, waiting-state first candidate, action receipt, reservations, single-use permit consumption, zero firewalls, actual accounting, append-only transitions and the three terminal outcomes. It cannot authorize itself, replay the predecessor or current permit, increase budgets, widen authority, modify frame semantics, merge main, force-push or access data.
