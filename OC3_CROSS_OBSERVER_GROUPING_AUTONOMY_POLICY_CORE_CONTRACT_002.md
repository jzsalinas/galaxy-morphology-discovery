# OC3 Cross-Observer Grouping Autonomy Policy Core Contract 002

## Purpose

This prospective universal policy decides only whether an epistemically
material action remains inside the frozen cross-observer grouping mandate.
Action-specific validators own scientific and transport correctness. Policy
Core 001, Candidate 001, and Resource Manifest 001 remain immutable historical
preauthorization evidence.

## Generic policy

The Policy Core contains no stage ID, candidate filename, command, resource
URL, scientific threshold, or matching rule. The waiting state alone binds the
first candidate by exact project-relative path and full-file SHA-256. Standing
authorization independently binds that waiting state and candidate.

The generic action contract requires exact specification, validator receipt,
implementation, command, literal manifest, branch, permit path, reservation,
retry, resume, authority, and firewall bindings. Reservations cannot exceed
the unchanged mission budgets. Runtime argv equality is checked before permit
consumption.

Every permit is immutable, SHA-bound, and single-use. Request attempts are
charged before transport construction and every body byte read is charged,
including bytes preceding failure. Completion requires a consumed permit, an
exact terminal SHA, bounded counters, and an append-only lifecycle record.
STOP and the four scientific terminals remain closed.

## Evidence capture

`UPSTREAM_IMMUTABILITY` and `LOCAL_IMMUTABLE_SNAPSHOT` are distinct. A literal
resource must declare `evidence_capture_mode`.

- `HASHED_RESPONSE_SNAPSHOT` binds an exact request and preserves the exact
  returned body locally with retrieval time, response metadata, and SHA-256.
  It makes no upstream immutability claim.
- `REVISION_PINNED_RESOURCE` additionally requires a nonempty prospective
  revision identity and verification method. The mode cannot be inferred from
  provider reputation, archival purpose, URL shape, or a boolean assertion.

Missing optional HTTP `ETag`, `Last-Modified`, or `Content-Length` values are
recorded as null. Redirects remain action-specific and fail closed unless
prospectively authorized.

## Git firewall

The V2 manifest binds this contract and both governor implementation files.
Mutation while active requires `STOP_REQUIRES_HUMAN`. Runtime evidence trees,
response bodies, scientific tables, archives, credentials, and noncompact
artifacts cannot be staged by the governor auditor.
