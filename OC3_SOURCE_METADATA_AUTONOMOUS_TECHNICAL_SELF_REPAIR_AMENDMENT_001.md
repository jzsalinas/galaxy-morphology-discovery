# OC3 Source-Metadata Autonomous Technical Self-Repair Amendment 001

Status: **PROSPECTIVE; OFFLINE IMPLEMENTATION ONLY; NO RUN-003 AUTHORITY**.

## Purpose and precedence

This amendment defines a bounded `AUTONOMOUS_TECHNICAL_SELF_REPAIR` class for
future OC3 source-metadata recovery mandates. It does not alter, reopen, resume,
or reinterpret Run-001 or Run-002. It grants no network, material, provider,
rights, or Run-003 authority.

Run-002 remains terminal at `STOP_REQUIRES_HUMAN` with reason
`POLICY_CORE_PATH_CANONICALIZATION_REPAIR_REQUIRED`. Its authorization, state,
contradiction, report, G01 terminal, raw response, permits, and ledger remain
historical evidence.

## Canonical path identity

The sole canonical artifact identity is the POSIX project-relative path under
the physical repository root. Executable argv uses the absolute path derived
from the same identity object. Relative input is interpreted only against an
explicit cwd. Dot and parent components may collapse only when the result
remains inside the repository. Existing symlink components, a symlinked
repository root, and paths outside the repository fail closed.

Candidate construction, candidate sealing, derived authorization binding,
governor validation, runner input validation, permit paths, output paths, and
capability paths must consume the shared `canonical_path_identity` primitive.
Independent string normalization is forbidden.

## Closed eligibility rule

A repair qualifies only when every condition is proven: it is local,
deterministically diagnosed, non-scientific, offline-testable, prospectively
recorded, confined to an explicitly authorized implementation surface, and
unambiguous from frozen authorities. Scientific semantics, observational
contracts, providers/resources, rights, permissions, caps, scope, and
acceptance criteria must each have measured drift zero. Historical evidence
must remain byte-identical.

The governing standing mandate must explicitly authorize both technical
self-repair and post-repair rebinding. Absence of either permission fails
closed.

Provider or mirror choice, representation or dataset meaning, scientific
thresholds, validation weakening, budget increases, network broadening,
rights interpretation, observational equivalence, source-value
reinterpretation, resource substitution, acceptance-criterion changes, and
new human value judgments are ineligible.

## Procedure

For an eligible defect a future active mission must:

1. classify the defect against the closed eligibility schema;
2. snapshot state, evidence, candidate, authorization, and implementation;
3. create a prospective repair proposal and episode identity;
4. patch only the authorized implementation surface;
5. run focused offline adversarial tests;
6. run the offline regression required for the changed surface;
7. compute a new implementation aggregate;
8. prove all governance drift fields remain zero;
9. commit the repair separately;
10. retain invalidated artifacts as historical evidence;
11. create fresh downstream candidate and derived authorization bindings; and
12. continue only when the standing mandate explicitly permits continuation.

An authorization or candidate whose technical binding names the prior
implementation aggregate is invalid after repair and cannot be reused.

## Finite limits

- Maximum self-repair episodes per mission: **2**.
- Maximum episodes for the same defect class: **1**.
- No recursive mutation of this amendment or its eligibility classifier.
- No repair when multiple materially different fixes are plausible.
- No repair when intended behavior is not uniquely derivable from frozen
  authorities.
- No repair after evidence indicates a provider-semantic, scientific,
  observational, rights, resource, or acceptance-boundary issue.

Crossing any limit produces `STOP_REQUIRES_HUMAN`.

## Human-stop boundary

`STOP_REQUIRES_HUMAN` remains mandatory for new scientific assumptions,
observational equivalences, providers/resources, credentials, secrets,
rights/licensing or redistribution decisions, higher budgets/caps, new
thresholds, material scope changes, ambiguous materially different repairs,
historical-evidence alteration, and every condition excluded above.
