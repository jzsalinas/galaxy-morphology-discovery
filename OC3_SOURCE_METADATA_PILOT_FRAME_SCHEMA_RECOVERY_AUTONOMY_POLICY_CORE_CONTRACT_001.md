# Pilot-Frame Schema Recovery Policy Core Contract 001

The manifest freezes this mission's governor and CLI by SHA-256. While active,
mutation or mismatch requires `STOP_REQUIRES_HUMAN`. The governor validates
the closed predecessor, exact provider-schema authorities, mandate, branch,
waiting-state first candidate, action receipt, reservations, single-use permit
consumption, zero firewalls, actual accounting, append-only transitions and
the three terminal outcomes. It cannot authorize itself, replay any consumed
permit, increase budgets, widen authority, discover a schema adaptively,
modify frame semantics, merge main, force-push or access data.
