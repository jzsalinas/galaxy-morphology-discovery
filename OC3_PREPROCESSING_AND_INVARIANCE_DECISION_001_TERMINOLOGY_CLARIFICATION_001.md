The authority contains the historical phrase “two-object OC-3 technical pilot.” In all current and future OC-3 work, that phrase is interpreted only as a reference to the technical development grouping then under discussion. It does not assert that an astronomical object, galaxy, source, target, segmentation unit, or morphology-learning unit has been defined.

## Binding terminology

The present OC-3 state contains exactly:

- **2 frozen technical development bricks**;
- **6 frozen observational windows**; and
- **0 defined astronomical objects for morphology learning**.

Until a separately authorized scientific-object definition stage creates and validates astronomical object units, the required term is:

> **two-brick / six-window technical pilot**

The six windows remain technical observational diagnostics. They must not be called galaxy examples, object crops, source cutouts, morphology instances, or a two-object sample.
